# 🧰 Server Commands

{% hint style="info" %}
Commands with a \* do **not** need moderator permissions to use.
{% endhint %}

<table><thead><tr><th width="207">Command</th><th>Description</th></tr></thead><tbody><tr><td><code>/ban</code></td><td>Bans up to 10 server members.</td></tr><tr><td><code>/block</code>*</td><td><strong><code>add</code></strong> adds a user to your block list,  <strong><code>remove</code></strong> removes a user, and <strong><code>list</code></strong> displays your current list. When creating a Starbot <a href="../settings-menu/voice-and-rooms/temporary-voice-channels.md">temporary VC channel</a>, the room will be hidden from users on this list (global).</td></tr><tr><td><code>/cleanup</code></td><td>Clears messages up to 2 weeks old from a channel by user, role, or message amount.</td></tr><tr><td><code>/rolemenu</code></td><td>Creates a role list for members to select a role. Can be set to single or multi-select.</td></tr><tr><td><code>/settings</code></td><td>Pulls up the main settings menu. You can see details <a href="../settings-menu/">here</a>.</td></tr><tr><td><code>/warnings</code></td><td><code>/warnings add</code> Increases a user's warning level<br><code>/warnings remove</code> Decreases a user's warning level<br><code>/warnings clear</code> Reduces a user's warnings to zero</td></tr></tbody></table>
