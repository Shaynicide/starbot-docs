# 🕹️ Mini-Games

Mini-games can be played from the menu using `/game`.

## Faker

A <mark style="color:yellow;">4-9 player</mark> game where everyone gets the question except for one person (the Faker). The Faker must try to blend in with the other players, cast suspicion on others, and escape without getting caught!

***

## Trivia Time

A <mark style="color:yellow;">1-9 player</mark> game of Trivia. You can select a category for the questions and battle to see who knows it all!

{% hint style="warning" %}
Rewards are not available for single player games.
{% endhint %}
