# ❔ FAQ

## Starbot isn't responding. Why?

It could be anything from the server lagging or being in the middle of a bot restart… but the most common cause is insufficient channel permissions. You can use `/permissions` to check that Starbot has the required permissions.\
\
The main required permissions are `View Channel`, `Send Messages`, and `Embed Links` permissions for the necessary channels.&#x20;

{% hint style="warning" %}
Starbot will usually send a DM alert, but if DMs are not allowed nothing will be sent.
{% endhint %}

***

## What if I chose the wrong language during setup?

You can always kick and re-invite the bot, but the the easier options is to use `/settings`. The option to switch languages will always be show in the opposite language, so you can easily find it there.

***

## In settings, there is a ⚠️ next to a role. Why?

This means that although a role is selected and set up, it is not manageable by Starbot. This means that Starbot cannot add it to users or remove it, and it needs to be moved below Starbot in the role hierarchy.

***

## Can I set a level reward role for Lv. 0?

Yes! Just be aware that this will also give the role to anyone who enters the server by default.

***

## A user keeps using items to rename other members. How can I stop this?

In the `/settings` menu, you can disable **"Troll Items"**, which are any items that override permissions (such as changing nicknames). Users can still obtain them, but will not be able to use them.
