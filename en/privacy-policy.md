# 🔓 Privacy Policy

This Privacy Policy explains what data Starbot collects, how that data is used, and how it is handled.

By using Starbot, you agree to this Privacy Policy. If you do not agree with this policy, you should not use Starbot.

***

### Collected Data

Starbot only stores data required for its features to function properly.

#### Server IDs

Server IDs are used to save server-specific settings and configuration.

#### Channel IDs

Channel IDs are used for features such as temporary voice channels, logging, alerts, and other server settings.

#### User IDs

User IDs are used to store user-related bot data, such as XP, levels, achievements, user preferences, game data, and other feature-related information.

#### Role IDs

Role IDs are used for features such as role menus, role rewards, welcome roles, and other role-giving features.

#### Message IDs

Message IDs may be stored for bot menus, message management, message deletion, moderation tools, and other bot features.

Starbot does not store Discord message content outside of Discord.

***

### How Data Is Used

Collected data is used only to provide, maintain, and improve Starbot’s features.

This includes server settings, moderation tools, temporary voice channels, XP and leveling, achievements, role features, user engagement features, and other bot functions.

Starbot does not sell user data.

***

### Data Access

Stored data is only accessible to Starbot and the bot owner/developer when needed to operate, maintain, debug, or support the bot.

Data is not shared with third parties except when required by law, Discord policy, or necessary to operate Starbot’s services.

***

### Data Security

Reasonable measures are taken to protect stored data from unauthorized access, copying, modification, or deletion.

However, no online service can guarantee complete security. Starbot is provided on an “as is” and “as available” basis.

***

### Data Retention

When Starbot is removed from a server, that server’s stored data is automatically deleted after 30 days.

Some data may be deleted sooner if it is no longer needed for Starbot’s features.

***

### Data Deletion Requests

You may request deletion of stored data by [contacting](contact.md) the bot owner/developer.

When requesting deletion, please include enough information to identify the relevant server, user, or data.

***

### Opting Out

You may stop using Starbot at any time by removing Starbot from your server or by not participating in Starbot features.

If Starbot is used in a server you are part of, some data may still be processed when you interact with Starbot or participate in server features that use Starbot.

If you do not want Starbot to store data related to you, you may request deletion using the contact method above. Some features may no longer work for you after your data is deleted.

***

### Changes to This Policy

This Privacy Policy may be updated at any time. The most current version will be available on the Starbot documentation site.

By continuing to use Starbot after changes are made, you agree to the updated Privacy Policy.
