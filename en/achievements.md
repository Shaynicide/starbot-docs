# 🏆 Achievements

Achievements are global (can be unlocked in any server) and are stored per user. You can check achivements that have been unlocked using `/achievements`.

In the achievement list, at first only achievement numbers and titles are displayed.

***

## Unlock Condition Hints

Upon unlock, the next achievement's unlock condition will be displayed. For example - if achievement #13 is unlocked, achievement #14's unlock condition will be viewable via `/achievements`.

{% hint style="info" %}
The more thoroughly you use Starbot, the more likely you are to stumble upon achievements!
{% endhint %}
