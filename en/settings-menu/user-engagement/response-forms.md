# ✍️ Response Forms

## Questions

When creating a response, users will be shown a form to fill out. When making a survey, begin a question with **`*`** to mark it as required. You can also choose different input types.

<table><thead><tr><th width="179.60003662109375">Input Type</th><th>Description</th></tr></thead><tbody><tr><td><mark style="color:$primary;">Text Input</mark></td><td>A basic text input</td></tr><tr><td><mark style="color:$primary;">File Upload</mark></td><td>Users can select a file to be uploaded</td></tr><tr><td><mark style="color:$primary;">User Select</mark></td><td>Users can select another user in the server</td></tr><tr><td><mark style="color:$primary;">Option List</mark></td><td>Users can choose from a list of options</td></tr></tbody></table>

***

## Styles

There are response formats that can be used for different situations.

<table><thead><tr><th width="179.60003662109375">Style</th><th>Description</th></tr></thead><tbody><tr><td><mark style="color:$primary;">Regular</mark></td><td>Each question will appear above its response</td></tr><tr><td><mark style="color:$primary;">Compact</mark></td><td>The question will stay in-line (for short labels, like <strong>Name</strong>)</td></tr><tr><td><mark style="color:$primary;">Ticket</mark></td><td>Responses have <strong>Mark Unresolved / In-Progress / Resolved</strong> buttons</td></tr><tr><td><mark style="color:$primary;">Forum</mark></td><td>Creates a thread in a forum channel</td></tr><tr><td><mark style="color:$primary;">Thread</mark></td><td>Creates a private thread and adds the user</td></tr></tbody></table>

***

{% hint style="info" %}
A <mark style="color:$primary;">role</mark> can be set to be mentioned each time there is a response.
{% endhint %}
