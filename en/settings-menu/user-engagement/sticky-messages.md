# 📌 Sticky Messages

## Overview

Sticky messages remain posted as the last message in a channel. They can be set to repost after either <mark style="color:$primary;">a set number of messages</mark> or <mark style="color:$primary;">after the last message after a certain time interval</mark>.

{% hint style="info" %}
One sticky message can be set per channel.
{% endhint %}
