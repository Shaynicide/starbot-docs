# 📈 XP & Level System

{% hint style="info" %}
Users can check the server XP leaderboard with **`/xp`**.
{% endhint %}

## XP Reset

When resetting the XP of all server members, you can specify a <mark style="color:$success;">reward role</mark> to give to anyone with a high enough level (specified in the settings). Setting <mark style="color:cyan;">Role Keep</mark> to **Off** will remove the role if a user has it but did not meet the requirement.

***

## XP Rate

The XP rate can be set from <mark style="color:$primary;">x0.00</mark> (off) to <mark style="color:$primary;">x5.00</mark>. You can also allow <mark style="color:pink;">server boosters</mark> to gain an additional <mark style="color:$primary;">0%</mark> to <mark style="color:$primary;">100%</mark> extra bonus.

{% hint style="danger" %}
The default XP rate is <mark style="color:$primary;">x0.00</mark>, so no XP will be gained unless changed.
{% endhint %}

***

## Level-Up Reward Roles

Roles can automatically be awarded for reaching certain levels in the server. When a new reward role is awarded, the old one will be replaced. Only one role can be assigned per level.&#x20;

{% hint style="info" %}
If you set a role for **level 0**, users will be granted the role on server entry.
{% endhint %}

{% hint style="warning" %}
Roles set as reward roles are **exclusive**, meaning that if a role is awarded, **all other roles included in the reward roles will be automatically removed.**
{% endhint %}

***

## Notifications & Exempt Channels

You can set notifications to be sent to a channel on level-up. They will display how many levels until the <mark style="color:$primary;">next</mark> <mark style="color:$primary;">reward role</mark> if applicable.

Any channels specified as **exempt** will not count toward XP gain.
